# Abdulrahman — Birthday Surprise Template

موقع Birthday تفاعلي جاهز للتخصيص.

## الملفات
- `index.html` — محتوى الموقع.
- `style.css` — التصميم والأنيميشن.
- `script.js` — العداد والتفاعل والأسئلة.
- `assets/photo.webp` — الصورة المؤقتة التي أرسلتها.

## التخصيص
ابحث داخل `index.html` عن الكلمات الموجودة بين الأقواس مثل:
- (اسمه)
- (اسمها)
- (أول حرف من اسمه)
- (أول حرف من اسمها)
- (تاريخ ميلادها)
- (الرسالة التي يريد إرسالها لها)
- (صورة)

واستبدلها ببيانات العميل.

### العداد
في `script.js`:
`birthdayDate: "2027-04-12T00:00:00"`

تم ضبطه حاليًا على مثال عيد ميلاد 12/04/2006، أي الموعد القادم 12/04/2027.
لأي عميل جديد غيّر التاريخ إلى موعد عيد ميلاده القادم.

### الصور
استبدل `assets/photo.webp` بالصور الحقيقية مع الحفاظ على الاسم، أو غيّر مسارات الصور في HTML.

### الموسيقى
ضع ملفًا باسم:
`assets/music.mp3`
وسيعمل زر الموسيقى الموجود أعلى الموقع.

## التشغيل
افتح `index.html` مباشرة أو ارفع المجلد على GitHub Pages / Netlify / أي استضافة ثابتة.
